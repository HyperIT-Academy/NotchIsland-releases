# NotchIsland — releases

Публічний реліз-репозиторій для автооновлення NotchIsland. Тільки підписані білди й
appcast.json — вихідний код лишається приватним у `HyperIT-Academy/NotchIsland`.

`appcast.json` (гілка `main`) — підписаний Ed25519 manifest останньої версії, читається
клієнтом як `https://raw.githubusercontent.com/HyperIT-Academy/NotchIsland-releases/main/appcast.json`.
Схема й процес публікації — `docs/tz-autoupdate.md` у приватному репо.
