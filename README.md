# NotchIsland

Острівець керування довкола чолки Mac: тема, «Не засинати», Night Shift, підсвітка клавіатури,
гучність окремих застосунків, кошик, блокування клавіатури, керування музикою.
Потрібна macOS 14.2 або новіша.

## Встановлення — одна команда

1. Відкрий **Термінал**: `Cmd + Пробіл` → «Термінал» → `Enter`.
2. Скопіюй рядок нижче (кнопка копіювання праворуч), встав у Термінал і натисни `Enter`:

```sh
curl -fsSL https://raw.githubusercontent.com/HyperIT-Academy/NotchIsland-releases/main/install.sh | sh
```

Команда сама встановить NotchIsland або оновить стару версію, перевірить підпис і запустить
застосунок — без вікон «не вдалось перевірити розробника» і зазвичай без пароля.
Далі оновлення приходять автоматично.

3. У вікні привітання натисни «Надати» біля потрібних дозволів і «Готово».
   Наведи курсор на чолку зверху екрана — острівець розкриється.

## Без Термінала

Завантаж [установник NotchIsland.pkg](https://github.com/HyperIT-Academy/NotchIsland-releases/releases/download/v0.5.29/NotchIsland-0.5.29.pkg)
і відкрий його. Якщо macOS не дає відкрити: **Системні параметри → Конфіденційність і безпека →
«Усе одно відкрити»**. Далі «Продовжити» → «Встановити» → пароль від Mac. Після встановлення
застосунок сам оновиться до останньої версії.

---

Технічне: `appcast.json` (гілка `main`) — підписаний Ed25519 manifest останньої версії, його
читають автооновлення та `install.sh`. Збірки — у GitHub Releases. Вихідний код приватний
(`HyperIT-Academy/NotchIsland`), процес публікації — `docs/tz-autoupdate.md` у ньому.
